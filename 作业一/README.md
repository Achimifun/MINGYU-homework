# 作业一：酱油风味物质 Lasso 降维（题目一）

**运行方式**：在本目录下执行 `pip install -r requirements.txt`，然后 `python lasso_analysis.py`。
脚本一键完成：读入标准化数据 → Z-score 校验 → LassoCV 10 折交叉验证（200 个 α）→ 三张 300 dpi 图（输出到 `figures/`）。

**文件清单**：`lasso_analysis.py`（代码）、`figures/fig1_lasso_paths.png`、`figures/fig2_cv_mse.png`、`figures/fig3_coefficients.png`、`requirements.txt`、本说明。课程数据 `data/` 按任务书要求未随仓库公开发布。

## 一、思路概览

1. **数据**：48 个酱油样品 × 6 次生物学重复 = 288 个观测，40 个风味指标（已 Z-score 标准化）。脚本先用 raw 文件重算 Z-score 与 standardized 文件逐元素比对（最大偏差 5.0e-15），确认标准化无误。
2. **为什么必须标准化**：Lasso 的 L1 惩罚对各变量对称，若量纲不同会不公平地偏向小量纲变量（NaCl g/100 mL 量级 vs 核苷酸 mg/100 mL 量级）。
3. **建模**：`LassoCV(n_alphas=200, max_iter=20000)`，10 折交叉验证（`KFold(n_splits=10)`），系数路径与 CV 误差曲线用同一 α 网格。

## 二、附加要求结果

### 1. 选定的 λ

| 准则 | λ | log10(λ) |
| --- | --- | --- |
| λmin（最小 CV-MSE） | **0.000531** | **-3.275** |
| λ1se（一倍标准误准则） | **0.001852** | **-2.732** |

### 2. λmin 下保留的指标数

40 个指标保留 **36 个**非零系数。

### 3. 被压缩为 0 的指标（4 个）

**甘氨酸（Gly）、亮氨酸（Leu）、苏氨酸（Thr）、缬氨酸（Val）**——恰好都是非必需/支链氨基酸，其信息已被其他强相关变量（如 Glu、Ala 等共线性氨基酸及无机盐离子）吸收。

### 4. 为什么选 λmin 而不是 λ1se

λ1se 处 CV-MSE（≈0.089）仅比 λmin（≈0.072）高约 24%，且已压掉 12 个变量、只剩 28 个，模型确实更简约；但本任务的目标是**降维+变量筛选**而非极致简约——λmin 之下 CV-MSE 曲线在 log10(λ)∈[-3.5,-3.2] 间相当平坦（误差棒互相重叠，两处差异折间波动即可解释，不显著），而 λmin 已把 4 个冗余氨基酸压到 0，保留了 Mg²⁺、K⁺、Lys 等与咸味机理明确相关的关键变量。若用 λ1se，部分中等强度信号（如 NaCl、NSSS）会进一步被过度收缩，不利于解释风味物质结构。因此选 **λmin**：它在不损失预测精度的前提下完成降维，保留的变量更完整。

## 三、主要发现

- **最强信号**：Mg²⁺（+0.704）与 K⁺（-0.556）、Lys（-0.276）——无机盐离子主导咸味感知，与"盐=NaCl"的直觉不同，Mg²⁺ 的标准化系数远大于 Na⁺/Cl⁻/NaCl 本身，提示镁离子对咸味强度有重要增强作用。
- 图 1 中灰色曲线（K⁺）与黄色曲线（Arg）随 λ 增大最先偏离 0，是最稳定的信号。
- 完整系数排序见 `figures/fig3_coefficients.png`。

## 四、可复现性

- 交叉验证：`KFold(n_splits=10)`（顺序 10 折划分，与任务书第七节参考值对齐）；`random_state=42` 贯穿全程。
- 复现参考值核对：λmin=0.000531（参考 ≈0.000531 ✓）、log10(λ1se)=-2.732（参考 ≈-2.75 ✓）、非零 36 个（参考 36 ✓）、压零 Gly/Leu/Thr/Val（参考一致 ✓）。
