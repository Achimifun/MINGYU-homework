# 题目二：Kaggle 泰坦尼克号生存预测 — 提交说明

**运行方式**：在本目录下执行 `pip install -r requirements.txt`，然后 `python titanic_analysis.py`。
脚本一键完成 EDA → 建模 → 四张图（300 dpi，输出到 `figures/`）→ `submission.csv`，并运行题目给的格式自查代码。

**文件清单**：`titanic_analysis.py`（代码）、`figures/fig1_eda.png ~ fig4_feature_importance.png`、`submission.csv`（418 行）、`requirements.txt`、本说明。

**纪律声明**：全程 `random_state=42`；交叉验证统一 `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`；
所有需要拟合的预处理（缺失值填充、标准化、One-hot 编码）全部放在 `Pipeline`/`ColumnTransformer`
内部，交叉验证每一折只用该折训练部分拟合；`test.csv` 只被 `transform`/`predict`，从未参与任何 `fit`。

## 一、思路概览

1. **EDA**（fig1）：按性别×舱位、年龄、票价、家庭规模四组观察生存率，找出最强信号；
2. **特征工程**：从 `Name` 提取 `Title`（题目要求项），派生 `FamilySize`/`IsAlone`/`HasCabin`；
3. **模型比较**（fig2）：分层 5 折 CV 比较性别基线、逻辑回归、随机森林、梯度提升 4 个模型（准确率 + ROC-AUC）；
4. **最佳模型评估**（fig3）：OOF 混淆矩阵 + 各折/汇总 ROC 曲线；
5. **特征重要性**（fig4）并生成 `submission.csv`。

**图 1 的主要观察**：最强信号是**性别**（女性生还率 74.2% vs 男性 18.9%）；其次是**舱位**（1 等
0.63 → 2 等 0.47 → 3 等 0.24，单调），且与性别存在交互——即使三等舱，女性仍有 0.50；
**家庭规模**呈倒 U 型（2~4 人生还率最高，独行与 ≥5 人低）；**票价**越高生还率越高（对数轴上
两条分布明显错开），与舱位强相关。

## 二、附加要求 1：各模型 5 折 CV 结果

| 模型 | Accuracy（均值 ± 折间 std） | ROC-AUC（均值 ± 折间 std） |
|---|---|---|
| Sex baseline (LR) | 0.7868 ± 0.0188 | 0.7667 ± 0.0234 |
| Logistic Regression | 0.8238 ± 0.0129 | 0.8747 ± 0.0175 |
| Random Forest | 0.8316 ± 0.0139 | **0.8831 ± 0.0213** |
| **Gradient Boosting（最终选用）** | **0.8417 ± 0.0167** | 0.8796 ± 0.0192 |

（性别基线 0.7868 与任务书第七节参考值一致；全部模型 CV 准确率在 0.81~0.85 区间、
AUC 0.87~0.88，符合任务书给出的合理范围，无泄漏迹象。）

## 三、附加要求 2：为什么选 Gradient Boosting

- 以准确率（本题与 Kaggle 的计分指标）为主指标，梯度提升最高（0.8417）；
- 但要诚实说明：它与随机森林的差距只有 0.0101，两者误差棒（±0.0167 / ±0.0139）**大幅重叠**，
  5 折样本量下这个差距**不显著**；AUC 上随机森林反而略高（0.8831 vs 0.8796，±0.021 的波动下同样
  分不出高下）。三者中只有"性别基线"能被明确排除；
- 复杂度/可解释性权衡：梯度提升与随机森林同为树集成，`feature_importances_` 可读性相当；
  逻辑回归最易解释（系数直接可读）但两项指标均最低。综合"主指标最高 + 次指标接近最高 +
  可解释性与随机森林同级"，选梯度提升，并把选择建立在重叠误差棒的诚实表述上，而非"它最高"。

## 四、附加要求 3：缺失值处理策略

| 列 | 缺失（train/test） | 策略 | 依据 |
|---|---|---|---|
| Age | 177 / 86（约 20%） | 中位数填充（Pipeline 内逐折拟合） | 年龄右偏（有高龄离群值），中位数比均值稳健；约 20% 缺失必须填而非删 |
| Fare | 0 / 1 | 用训练集中位数填充 | 仅测试集缺 1 个；绝不用测试集自身统计量（只能 transform） |
| Embarked | 2 / 0 | 众数填充（S） | 只缺 2 行，最简单合规的做法即可；（可细分：这两人票价 80 与 C 港头等舱票价吻合，填 C 更精细，但 2/891 影响可忽略） |
| Cabin | 687 / 327（77%） | **不填充**，转为 `HasCabin` 0/1 | 缺失太多填不了真值；缺失模式本身是信息——有舱位记录的几乎都是高等舱乘客，生还率 0.67 vs 0.30 |

**为什么不用"直接删行"**：① 测试集 418 行每一行都必须给出预测，缺 Age/ Fare 的行不能删；
② 训练集删 177 行会丢掉 20% 样本，且缺失并非随机——Age 缺失集中在三等舱（其生还率本身低），
删行会引入偏倚；③ 任务书纪律要求所有填充在 Pipeline 内逐折拟合，这保证填充值永远只来自
训练部分，测试集只被 transform。

## 五、附加要求 4：构造的全部新特征

| 特征 | 一句话建模含义 |
|---|---|
| `Title` | 从 `Name` 按正则 `,\s*([^\.]+)\.` 提取称谓：`Mlle/Ms→Miss`、`Mme→Mrs` 合并，低频称谓按性别并入 `Mrs`/`Rare`——区分"男童 Master"与"成年男性 Mr"，同时还原性别、婚否与社会地位 |
| `FamilySize` | `SibSp + Parch + 1`：一家人同行互助逃生更容易，但 ≥5 人行动慢，呈倒 U 效应 |
| `IsAlone` | 是否独行（FamilySize==1）：独行乘客生还率最低的粗粒度标记 |
| `HasCabin` | Cabin 是否有记录：高等舱/社会阶层的强代理变量 |
| `log1p(Fare)` | 票价严重右偏（中位 14.45，最大 512.33），取对数后接近正态，线性模型的线性假设更成立 |
| `Sex / Embarked / Title` 的 One-hot | 名义变量展开为 0/1 哑变量（Embarked 是名义变量，不能用 0/1/2 当数值编码） |
| `Pclass` 保留**有序数值**（未 one-hot） | 1>2>3 的等级序有真实含义且生还率单调（0.63/0.47/0.24），有序编码保留这个序信息；树模型可直接利用切点，线性模型将其作为单调线性项——若用 one-hot 反而拆掉序信息且多 2 列 |

## 六、附加要求 5：预测生还比例 vs 训练集生还率

`submission.csv` 预测生还 **153 / 418 = 36.6%**；训练集生还率 **38.4%**；官方基线
`gender_submission.csv` 为 **36.4%**。

**差异解释**：测试集与训练集是同一总体随机划分出的两批人，生还率存在抽样波动；418 人规模下
1.8 个百分点 ≈ 7.5 人，落在二项分布的合理波动范围内（gender_submission 的 36.4% 同样低于
38.4%，方向一致）。另一方面模型并未系统性压低生还预测——混淆矩阵显示 OOF 阶段真实生还者
74.3% 被正确召回，判死倾向（FP 53 人 vs FN 88 人）大体对称。因此 36.6% 与 38.4% 的差异
是合理的数据构成差异，不是模型偏差。

## 七、结果要点（fig3 / fig4）

- **混淆矩阵**（891 人 OOF）：真实遇难者召回 90.3%（496/549），真实生还者召回 74.3%（254/342）；
- **ROC**：各折 AUC 0.852~0.901，全部 OOF 汇总 AUC = 0.880；
- **特征重要性前五**（feature_importances_）：`Title_Mr` 0.469、`Fare` 0.162、`Pclass` 0.108、
  `Age` 0.075、`FamilySize` 0.065——与 EDA 观察一致：称谓（性别×年龄身份）是最强信号，
  one-hot 哑变量如实单列（`Title_Mr` 高也意味着 `Title_Mrs/Miss` 的对照作用，性别信息已由
  `Title` 覆盖，故 `Sex_male` 重要性趋近 0）。
